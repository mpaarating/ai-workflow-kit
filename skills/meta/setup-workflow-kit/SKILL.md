# Setup Workflow Kit

## Trigger Phrases

- "setup workflow kit"
- "setup skills"
- "/setup-workflow-kit"

## Workflow

1. **Read the existing config** at `integrations/active.md` if it exists. If it does, show the current setup and ask whether to keep, modify, or reset.

2. **Ask the four integration questions** one at a time. For each, present the supported options plus "other" (free-text). Recommended option is marked.

   - **Notes** — where daily pages, journal entries, and saved content go
     - Notion *(recommended if you already use it)*
     - Obsidian (vault path)
     - Plain markdown (a directory like `~/.ai-workflow/`)
     - Other

   - **Tasks** — where todos, tickets, and assigned work live
     - Jira
     - Linear
     - GitHub Issues
     - Local `TODO.md`
     - Other

   - **Calendar** — used by morning-kickoff and meeting-prep
     - Google Calendar
     - Apple Calendar
     - None *(skills will skip calendar lookups)*
     - Other

   - **Chat** — used by capture, meeting-prep, and save for threads
     - Slack
     - Discord
     - Microsoft Teams
     - None
     - Other

3. **Ask about auth strategy**:
   - **Zapier MCP** *(recommended — one login, covers most apps)*
   - **Direct API keys** (env vars per service)
   - **Markdown-only** (zero auth — only works if all four answers above are "markdown" or "none")

4. **Write `integrations/active.md`** in the same shape as `integrations/active.example.md`. Per-service subsections with API/endpoint details and a "How skills use it" line so other skills have a concrete reference:

   ```markdown
   # Active Integrations

   <!-- Generated by /setup-workflow-kit. Edit manually or re-run to reconfigure. -->

   ## AI Tool: <choice>
   <how skills are installed in this agent>

   ## Auth: <choice>
   <connection/credentials reference>

   ---

   ## Notes: <choice>
   - **API**: <MCP server or API name>
   - **Identifiers**: <database IDs, vault path, or directory>
   - **How skills use it**: <one-line description>

   ## Tasks: <choice>
   - ...

   ## Calendar: <choice>
   - ...

   ## Chat: <choice>
   - ...
   ```

   When a section's value is "none" or "markdown", still include the subsection but mark it as such (other skills branch on it).

5. **Confirm and point to next steps**:
   - "Setup complete. Try `/morning-kickoff` to create today's page."
   - If env vars are needed, list which ones.
   - If a service-specific MCP server is required (e.g., Notion, Atlassian), name it.

## Notes

- This skill is idempotent. Running it again replaces `integrations/active.md` after confirmation.
- For users not on Claude Code, the same logic exists in `setup.sh` at the repo root.
- This is a meta-skill, not a workflow skill. It does not write to `{{notes}}` or any user data.
