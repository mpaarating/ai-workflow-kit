# Notes

Capture and routing. Anything that takes input and persists it.

- **[capture](./capture/SKILL.md)** — Quick append to today's daily page. Free-form notes, chat threads, ticket references, document links.
- **[save](./save/SKILL.md)** — Intelligent routing of content to its right long-term home (project page, knowledge base, reference doc). Always asks where.
- **[journal](./journal/SKILL.md)** — Quick journal entries linked to your daily work log.
- **[todo](./todo/SKILL.md)** — Capture tasks to your preferred task system.
- **[read-later](./read-later/SKILL.md)** — Save articles with AI-generated summaries.
