# Daily

The daily flow loop. One skill for each transition point in a working day.

- **[morning-kickoff](./morning-kickoff/SKILL.md)** — Create today's daily page with calendar, tasks, and yesterday's carry-forwards.
- **[top-priority](./top-priority/SKILL.md)** — Read-only answer to "what should I work on right now?" Cross-references time, meetings, and progress.
- **[checkin](./checkin/SKILL.md)** — Midday progress check. Compares the morning plan to actual work and refocuses the afternoon.
- **[tend](./tend/SKILL.md)** — Mid-afternoon page tidying. Checks off completed items, surfaces buried actions, flags stale carry-forwards.
- **[eod-review](./eod-review/SKILL.md)** — End-of-day review. Captures what shipped, prepares tomorrow's carry-forwards.
